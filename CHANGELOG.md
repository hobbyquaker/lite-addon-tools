# Changelog

## [2026.08.1.1] - 2026-11-11

- First public release, for openccu-lite 1.2.1 and later (the tools on the login shell's search path): socat, tcpdump, strace, nmap, htop, iotop, nano, mtr, iperf3, drill, ss, iftop, arp-scan, tmux, ncdu, picocom, lsof, pstree, prtstat, mmc and gdbserver, built statically with Buildroot 2026.08.1 and Bootlin's musl toolchain for aarch64 and x86_64; OpenSSL from the 3.5 LTS series. (released by the follow-buildroot workflow)

## [2026.08.1.1-dev] - 2026-11-08

- First version (Gitea only): socat, tcpdump, strace, nmap, htop, iotop-c, nano, mtr, iperf3, drill (ldns), ss
  (iproute2), iftop, arp-scan, tmux, ncdu, picocom, lsof, psmisc (pstree, prtstat), mmc-utils and gdbserver,
  built statically with Buildroot 2026.08.1 and Bootlin's musl toolchain for aarch64 and x86_64.
